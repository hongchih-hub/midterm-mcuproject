# midterm-mcuproject
# 戰術拆彈模擬器 - 核心邏輯劇本

本專案採用「替身思維」，無須外接真實致動器（如繼電器）或額外燈號。引爆與倒數狀態將完全透過 **電腦終端機 (UART)** 與 **無源蜂鳴器 (PWM)** 進行演出。

## 1. 系統變數與開機設定 (Setup)

**記憶體裡記錄的關鍵變數：**
*   **炸彈狀態**：目前處於 `準備中`、`倒數中` 還是 `已引爆`？（開機預設為 `準備中`）。
*   **剩餘時間**：預設為 60000 毫秒（60 秒）。
*   **死亡原因**：記錄是被遠端引爆、剪線、搖晃、還是時間到。

**開機瞬間要做的硬體初始化：**
*   **時脈**：設定系統時脈 170MHz。
*   **主控台**：啟用 UART 接收中斷，隨時聽取終端機指令。
*   **防拆陷阱**：設定 PA0 為下降緣/上升緣中斷，準備偵測搖晃。
*   **剪線陷阱**：設定 PA10、PA11、PA12 為輸入上拉 (Input Pull-up)，維持高電位防護網，等待實體杜邦線被拔除。
*   **系統宣告**：於終端機印出提示字串 `[系統啟動] 炸彈準備就緒，請輸入 START 開始倒數。`

---

## 2. 突發事件處理 (Interrupts - 最高優先級)

此區塊程式碼平時不執行，僅在特定「事件」發生時瞬間觸發。

*   **事件 A：電腦終端機傳來字元 (UART 中斷)**
    *   動作：將接收到的字元存入環形緩衝區 (Ring Buffer)。
    *   判斷：若字串組成 `START`，將炸彈狀態切換為 `倒數中`。
    *   判斷：若字串組成 `DETONATE`，強制將狀態切換為 `已引爆`，並記錄死因為「遠端主控台強制引爆」。
*   **事件 B：炸彈被移動或搖晃 (EXTI 防拆中斷)**
    *   動作：強制將炸彈狀態切換為 `已引爆`。
    *   動作：記錄死因為「防護機制觸發：異常震動」。
*   **事件 C：時間滴答 (Timer 中斷)**
    *   動作：每過 1 毫秒，若狀態為 `倒數中`，則「剩餘時間」變數減 1 毫秒。

---

## 3. 主迴圈 (Main Loop - 狀態機)

無窮迴圈，系統根據當下的「炸彈狀態」持續執行對應行為。

*   **當狀態是【準備中】：**
    *   蜂鳴器保持靜音。
    *   系統閒置，等待 UART 中斷將狀態改變。

*   **當狀態是【倒數中】：**
    *   **檢查時間**：若剩餘時間歸零，狀態切換為 `已引爆`，記錄死因為「倒數結束」。
    *   **檢查剪線陷阱 (Polling)**：持續輪詢 PA10、PA11、PA12 的電壓狀態。若發現任一腳位電壓由 0V 變為 3.3V（接地線路遭破壞），立刻將狀態切換為 `已引爆`，記錄死因為「防護機制觸發：實體線路遭剪斷」。
    *   **播放動態音效 (PWM)**：
        *   若剩餘時間 > 10 秒：控制 PWM 每秒觸發一次短暫的嗶聲 (1Hz)。
        *   若剩餘時間 ≤ 10 秒：控制 PWM 每秒觸發四次急促的嗶聲 (>4Hz)，營造倒數壓迫感。

*   **當狀態是【已引爆】：**
    *   **死亡宣告**：終端機印出 `[BOOM] 炸彈已引爆！` 以及對應的死亡原因。
    *   **長鳴警報**：啟動 PWM，對無源蜂鳴器穩定輸出 1kHz 的連續長鳴音。
    *   **鎖死系統**：進入無窮小迴圈 (While(1))，凍結所有倒數與判定邏輯，必須按下板載 Reset 按鍵方可重啟系統。
