# 戰術拆彈模擬器 - 核心邏輯劇本 (視覺加強版)

本專案採用「替身思維」，無須外接真實致動器。引爆與倒數狀態將完全透過 **電腦終端機 (UART)**、**無源蜂鳴器 (PWM)** 以及 **外接紅綠 LED** 進行演出。

## 1. 系統變數與開機設定 (Setup)

**記憶體裡記錄的關鍵變數：**
*   **炸彈狀態**：預設為 `準備中`。狀態包含：`準備中`(SAFE)、`待命中`(STANDBY)、`倒數中`(COUNTDOWN)、`已引爆`(DETONATED)。
*   **剩餘時間**：初始為 0 毫秒，等待動態賦值。
*   **呼吸燈亮度參數**：用於控制綠燈漸亮漸暗的計數變數。

**開機瞬間要做的硬體初始化：**
*   **主控台**：啟用 UART 接收中斷 (PA2/PA3)。
*   **防護陷阱**：PA0 (EXTI 搖晃中斷)、PA10~PA12 (GPIO 剪線輪詢，內部上拉)。
*   **音效模組**：PA8 設定為 Timer PWM 輸出 (1kHz 音頻用)。
*   **視覺燈號 (新增)**：
    *   **綠燈 (PA6)**：設定為 Timer PWM 輸出 (負責呼吸燈漸變與閃爍)。
    *   **紅燈 (PA7)**：設定為 GPIO 輸出 (負責倒數警告與引爆長亮)，預設為低電位(熄滅)。
*   **系統宣告**：印出 `[系統啟動] 炸彈保險已開啟。請輸入 START 啟動引爆程序。`

---

## 2. 突發事件處理 (Interrupts)

*   **UART 中斷**：處理 `START`、`[數字]s`、`DETONATE` 等指令切換狀態與設定秒數。
*   **EXTI 防拆中斷**：若狀態為 `待命中` 或 `倒數中` 則引爆；若為 `準備中` 則忽略。
*   **Timer 中斷 (1ms 滴答)**：負責倒數時間遞減，以及推動呼吸燈的亮度變化（改變綠燈 PWM 佔空比）。

---

## 3. 主迴圈 (Main Loop - 狀態機)

*   **當狀態是【準備中】(Safe)：**
    *   **燈號表現**：**綠燈呈現呼吸燈效果** (PWM 佔空比自動來回漸變)。紅燈熄滅。
    *   **其他**：蜂鳴器靜音。陷阱不觸發。

*   **當狀態是【待命中】(Standby)：**
    *   **燈號表現**：**綠燈改為閃爍模式** (佔空比強制設為 100% 維持 1.5秒，再設為 0% 維持 1.5秒，交替閃爍)。紅燈維持熄滅。
    *   **陷阱武裝**：持續輪詢 PA10~PA12，遭剪斷即引爆。

*   **當狀態是【倒數中】(Countdown)：**
    *   **燈號表現 (切換為主警告)**：綠燈完全熄滅。**紅燈與蜂鳴器同步作動**。
    *   **動態音效與紅燈閃爍 (漸進加速版)**：
        *   **若剩餘時間 > 15000 毫秒 (15秒)**：維持固定頻率 1Hz（每 1000 毫秒觸發一次短嗶聲與紅燈亮起）。
        *   **若剩餘時間 ≤ 15000 毫秒 (進入危險期)**：觸發間隔時間隨「剩餘時間」等比例動態縮短。隨著倒數逼近，嗶聲與紅燈閃爍會越來越快，直到引爆前達到極速狂閃。
    *   **陷阱檢查**：時間歸零或線路遭剪斷即引爆。

*   **當狀態是【已引爆】(Detonated)：**
    *   **燈號表現**：綠燈熄滅。**紅燈恆亮 (Solid Red)**，帶來視覺上的終結感。
    *   **死亡宣告**：印出 `[BOOM]。
    *   **長鳴警報**：蜂鳴器連續長鳴 1kHz。
    *   **鎖死系統**：進入無窮小迴圈，等待實體 Reset。
