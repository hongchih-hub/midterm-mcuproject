# midterm-mcuproject
# 戰術拆彈模擬器 - 核心邏輯劇本 (動態設時版)

本專案採用「替身思維」，無須外接真實致動器。引爆與倒數狀態將完全透過 **電腦終端機 (UART)** 與 **無源蜂鳴器 (PWM)** 進行演出。系統具備嚴格的「保險」與「動態設時」機制，確保操作互動的真實感。

## 1. 系統變數與開機設定 (Setup)

**記憶體裡記錄的關鍵變數：**
*   **炸彈狀態**：共有四種模式 `準備中` (保險開啟)、`待命中` (陷阱武裝)、`倒數中` (計時啟動)、`已引爆`。開機預設為 `準備中`。
*   **剩餘時間**：初始為 0 毫秒，等待終端機動態賦值。
*   **死亡原因**：記錄是被遠端引爆、剪線、搖晃、還是時間到。

**開機瞬間要做的硬體初始化：**
*   **時脈**：設定系統時脈 170MHz。
*   **主控台**：啟用 UART 接收中斷。
*   **防拆陷阱**：設定 PA0 為 EXTI 中斷，準備偵測搖晃。
*   **剪線陷阱**：設定 PA10、PA11、PA12 為輸入上拉 (Input Pull-up)，維持高電位防護網。
*   **系統宣告**：於終端機印出 `[系統啟動] 炸彈保險已開啟。請輸入 START 啟動引爆程序。`

---

## 2. 突發事件處理 (Interrupts - 最高優先級)

*   **事件 A：電腦終端機傳來字元 (UART 中斷)**
    *   動作：將接收到的字串存入環形緩衝區 (Ring Buffer)。
    *   判斷 1：若為 `START` 且在 `準備中`：切換為 `待命中`，並印出 `[武裝完成] 陷阱已作動，請輸入倒數秒數 (例如: 10s, 15s)`。
    *   判斷 2：若收到 `[數字]s` (如 `10s`) 且在 `待命中`：將數字解析並換算為毫秒存入「剩餘時間」，切換為 `倒數中`，並印出 `[倒數開始] 剩餘 XX 秒`。
    *   判斷 3：若收到 `DETONATE` 且狀態大於 `準備中`：強制切換為 `已引爆`，記錄死因「遠端主控台強制引爆」。

*   **事件 B：炸彈被移動或搖晃 (EXTI 防拆中斷)**
    *   **保險判斷（關鍵）**：檢查當前狀態。
        *   若為 `待命中` 或 `倒數中` (已武裝)：強制將炸彈狀態切換為 `已引爆`，記錄死因「防護機制觸發：異常震動」。
        *   若為 `準備中` (保險開啟)：忽略此事件，跳出中斷。

*   **事件 C：時間滴答 (Timer 中斷)**
    *   動作：每過 1 毫秒，**僅當狀態為 `倒數中` 時**，「剩餘時間」變數減 1 毫秒。

---

## 3. 主迴圈 (Main Loop - 狀態機)

*   **當狀態是【準備中】(Safe)：**
    *   系統閒置，蜂鳴器靜音。防拆與剪線感測雖有硬體作動，但軟體邏輯不觸發。

*   **當狀態是【待命中】(Standby)：**
    *   **陷阱已武裝**：持續輪詢 PA10、PA11、PA12。若發現任一腳位電壓由 0V 變為 3.3V（線路遭破壞），立刻將狀態切換為 `已引爆`。
    *   等待使用者輸入倒數時間。

*   **當狀態是【倒數中】(Countdown)：**
    *   **檢查時間**：若剩餘時間歸零，狀態切換為 `已引爆`，記錄死因「倒數結束」。
    *   **檢查剪線陷阱**：同上，持續輪詢，一斷線即引爆。
    *   **播放動態音效 (PWM)**：
        *   若剩餘時間 > 10000 毫秒 (10秒)：PWM 每秒觸發一次短暫嗶聲 (1Hz)。
        *   若剩餘時間 ≤ 10000 毫秒：PWM 每秒觸發四次急促嗶聲 (>4Hz)。

*   **當狀態是【已引爆】(Detonated)：**
    *   **死亡宣告**：終端機印出 `[BOOM] 炸彈已引爆！` 以及對應的死亡原因。
    *   **長鳴警報**：PWM 對無源蜂鳴器穩定輸出 1kHz 連續長鳴音。
    *   **鎖死系統**：進入無窮小迴圈 (While(1))，凍結所有邏輯，必須按下板載 Reset 按鍵方可重啟。
